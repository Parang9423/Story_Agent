# Story Agent

Story Agent is a story-development assistant app for building fictional worlds, characters, relationships, plots, scenes, dialogue, and continuity checks.

## Core Direction

This repository focuses on the main story creation workflow first.
Animation/image/video production features are treated as optional downstream production modules.

## Main Domains

- World Builder
- Map Builder
- Character Builder
- Relationship Builder
- Story Architect
- Scene Writer
- Continuity Check
- Knowledge Base

## Tech Stack

- React
- TypeScript
- Vite
- Supabase
